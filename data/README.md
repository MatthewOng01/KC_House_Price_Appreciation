# Data

## `price_data.csv`

This file is too large to host on GitHub (37 MB compressed) and is not included in this repo.

**To use it:**
1. Download it from [Google Drive](https://drive.google.com/file/d/1zLIu30NSLEpAITFTQud6r72ZWUB_jpzl/view?usp=sharing)
2. Unzip it
3. Place `price_data.csv` in this `data/` folder

`analysis.R` expects the file at this path and will not run without it.
