# Data

## `zillow_sfh_price.csv`

This file is too large to host on GitHub (52 MB compressed) and is not included in this repo.

**To use it:**
1. Download it from [Google Drive](https://drive.google.com/file/d/1h_bw3fBTpfNpRupQsVTceoRj4dIr_2jM/view?usp=sharing)
2. Unzip it
3. Place `price_data.csv` in this `data/` folder

`analysis.R` expects the file at this path and will not run without it.
